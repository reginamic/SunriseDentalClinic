# Sunrise Dental Clinic Management System

Sunrise Dental Clinic Management System is a distributed Java web application developed for the CIS6003 Advanced Programming module.

## Planned Architecture

Browser / JSP Web Application
→ REST Web Service
→ Business Logic Layer
→ DAO / Repository Layer
→ MySQL Database

## Technologies

- Java
- Jakarta EE
- JSP and Servlets
- REST Web Services
- JDBC
- MySQL
- Apache Tomcat
- Maven
- JUnit
- Git and GitHub
